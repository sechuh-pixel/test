# 환영합니다! 🎉

이 사이트는 **MKDocs**와 **Material for MKDocs** 테마를 사용하여 구축된 문서 사이트입니다.

## 📚 이 문서 사이트 소개

이 문서는 GitHub 저장소에 호스팅되며, GitHub Pages를 통해 자동으로 배포됩니다.

### 주요 기능

- ✨ **빠르고 간단한 설정** - MKDocs는 설정이 간단합니다
- 🎨 **Material 디자인** - 모던하고 깔끔한 UI
- 🔍 **강력한 검색 기능** - 실시간 검색 및 하이라이트
- 📱 **반응형 디자인** - 모든 기기에서 최적화된 표시
- 🌐 **다국어 지원** - 한국어 포함 다양한 언어 지원

## 🚀 시작하기

문서를 작성하려면 `docs/` 디렉토리 안에 Markdown 파일을 생성하세요.

```bash
# 로컬에서 미리보기
mkdocs serve

# 사이트 빌드
mkdocs build

# GitHub Pages에 배포
mkdocs gh-deploy
```

## 📖 문서 구조

이 사이트의 기본 구조는 다음과 같습니다:

```
test/
├── docs/
│   ├── index.md          # 메인 페이지 (이 파일)
│   ├── getting-started.md
│   ├── guide.md
│   └── api.md
├── mkdocs.yml            # MKDocs 설정 파일
└── requirements.txt      # Python 의존성
```
